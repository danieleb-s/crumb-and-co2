# Crumb & Co. Bakery

## Project Description
A simple website for a bakery, made with React JS. It has a Home page, About page, Our Bakes page and Contact page with a form.

## Technologies Used
React JS, React Router, Vite, HTML, CSS, Git and GitHub

## Features
- Four pages with navigation (React Router)
- Reusable ProductCard component that uses props
- Products shown with .map()
- Menu button for small screens and a button that shows opening hours (useState)
- Contact form with validation and a success message
- Responsive design using Flexbox, Grid and a media query

## Installation
1. Download or clone this repository
2. Open the folder in VS Code
3. Run `npm install`

## Running the Application
Run `npm run dev` and open the link shown in the terminal.
